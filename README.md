# 🚀 Python to Java Translator (BETA)

Bem-vindo ao **Python to Java Translator**, um projeto desenvolvido por uma equipe de **4 pessoas** com o objetivo de facilitar o aprendizado e a transição entre as linguagens **Python** e **Java**.
Este projeto foi criado especialmente para estudantes, programadores iniciantes e desenvolvedores que já possuem conhecimento em Python e desejam começar a aprender Java de uma forma mais rápida, prática e intuitiva.

## 📖 O que é o Python to Java Translator?
O Python to Java Translator é uma ferramenta experimental capaz de analisar códigos escritos em Python e convertê-los para a linguagem Java. O principal objetivo do programa não é apenas traduzir código, mas também ajudar o usuário a compreender como estruturas, comandos e conceitos de Python funcionam quando aplicados em Java.
A ferramenta foi desenvolvida para servir como um apoio educacional, permitindo que usuários comparem códigos das duas linguagens e aprendam suas diferenças e semelhanças durante o processo de conversão.

## ⚙️ O que o programa faz?

O programa é capaz de auxiliar na conversão de diversos elementos comuns da linguagem Python para Java, incluindo:

* Declaração de variáveis;
* Estruturas condicionais (if, else, elif);
* Estruturas de repetição (for e while);
* Funções e métodos;
* Impressão de texto e entrada de dados;
* Operações matemáticas e lógicas;
* Listas e estruturas básicas;
* Conversão de sintaxe geral;
* Organização inicial do código Java.

## 🎯 Como este programa pode ajudar você?

Se você já sabe programar em Python, aprender Java pode ser um desafio devido às diferenças de sintaxe e estrutura. O Python to Java Translator foi criado justamente para diminuir essa dificuldade.

Com ele, você poderá:

✔️ Entender como comandos Python são escritos em Java;
✔️ Aprender a estrutura básica da linguagem Java mais rapidamente;
✔️ Comparar códigos entre as duas linguagens;
✔️ Praticar programação orientada a objetos;
✔️ Economizar tempo durante os estudos;
✔️ Facilitar sua transição entre linguagens;
✔️ Utilizar exemplos práticos para aprimorar seu aprendizado.

Nosso objetivo principal é transformar o processo de aprendizado de Java em algo mais acessível para pessoas que já possuem experiência prévia com Python.
